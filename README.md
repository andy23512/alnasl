# Alnasl

An unofficial practice tool for the built-in mouse of CharaChorder 3D input devices (CharaChorder One, CharaChorder Two, CCU and Master Forge)

## Links

- [Website](https://andy23512.github.io/alnasl/)

## Background

CharaChorder 3D input devices have a built-in [mouse mode](https://docs.charachorder.com/GenerativeTextMenu.html#mouse) driven by two 4-way joysticks: moving both joysticks in the same direction moves the cursor at **Fast** speed, while moving only one joystick moves it at **Slow** speed. Alnasl trains the skill that mouse mode actually demands: a fast, coarse approach followed by a slow, accurate landing on the target.

## Features

- Practice modes, all built around a ring of targets so every movement direction gets covered
  - Move - reach the target and hold still on it, no click needed
  - Click - the standard move-then-click task
  - Drag - press on the pickup point, drag onto the target, then release
- Configurable difficulty - target count, rounds, target size, and movement distance
- Live HUD - current trial and running error count during a session
- Session results - error rate, average movement time, and throughput (a Fitts's law bits/s score combining speed and accuracy)
- Statistics page - charts your recorded sessions over time, split by mode
- English and Traditional Chinese UI
